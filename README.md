# fe-ecommerce-carreraarian

Frontend Angular (guía "Integración FE y BE parte II") para el backend `be-ecommerce-carreraarian`.

## Ejecutar
1. Levantar el backend en `http://localhost:8080` (con MySQL y un usuario creado en la tabla `usuarios`).
2. `npm install` (si falla con un error de npm, usar `npm install --legacy-peer-deps`)
3. `npm start` y abrir `http://localhost:4200`

La URL del backend se cambia en `src/environments/environment.ts`.
